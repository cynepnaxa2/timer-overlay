# Инструкция по созданию релиза на GitHub

## Шаг 1: Сборка .exe файла

Сначала соберите исполняемый файл:

```bash
npm run build:portable
```

Или используйте скрипт:
```bash
# Windows
build.bat

# Linux/Mac
./build.sh
```

После сборки файл будет находиться в папке `dist/` с именем `its-time-portable.exe`

## Шаг 2: Создание релиза через веб-интерфейс GitHub

1. **Перейдите на страницу репозитория:**
   - Откройте https://github.com/cynepnaxa2/its-time (или ваш репозиторий)

2. **Создайте новый релиз:**
   - Нажмите на кнопку "Releases" (справа в меню)
   - Или перейдите напрямую: https://github.com/cynepnaxa2/its-time/releases/new

3. **Заполните информацию о релизе:**
   - **Tag version:** `v1.0.0` (или другая версия)
   - **Release title:** `It's time! v1.0.0` (или просто `v1.0.0`)
   - **Description:** 
     ```
     Первый релиз It's time!
     
     ## Что нового:
     - Базовый функционал: красный круг, движущийся по экрану
     - Три уровня отображения: базовый, продвинутый, эксперт
     - Восемь режимов мотивации
     - Статистика по каждому режиму
     - Полная настройка внешнего вида и анимации
     - Горячие клавиши для сброса счетчиков
     - Автозапуск с Windows
     - Иконка в системном трее
     ```

4. **Прикрепите файл:**
   - Перетащите файл `its-time-portable.exe` из папки `dist/` в область "Attach binaries"
   - Или нажмите "selecting them" и выберите файл

5. **Опубликуйте релиз:**
   - Нажмите кнопку "Publish release"

## Шаг 3: Проверка

После создания релиза:
- Файл будет доступен для скачивания по ссылке: https://github.com/cynepnaxa2/its-time/releases
- Ссылка в README.md будет работать корректно

## Альтернативный способ: через GitHub CLI

Если у вас установлен GitHub CLI (`gh`), можно создать релиз через командную строку:

```bash
# Сначала создайте тег
git tag v1.0.0
git push origin v1.0.0

# Затем создайте релиз
gh release create v1.0.0 dist/its-time-portable.exe \
  --title "It's time! v1.0.0" \
  --notes "Первый релиз It's time!"
```

## Обновление версии

При создании новых релизов:
1. Обновите версию в `package.json`
2. Соберите новый .exe файл
3. Создайте новый релиз с новым тегом (например, `v1.1.0`)
