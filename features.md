## ✅ Реализовано

### Основные функции:

1. ✅ **Виджет с движущимся объектом**
   - Красный круг (или другой объект) движется вдоль правого края экрана снизу вверх
   - Яркий, полупрозрачный, не кликабельный
   - Равномерно преодолевает высоту монитора за заданное время (по умолчанию 60 секунд)
   - Не мешает кликать другие окна

2. ✅ **Окно настроек**
   - Доступно из системного трея
   - Настройка размера объекта (10-200px, по умолчанию 60px)
   - Настройка прозрачности (0.1-1.0)
   - Настройка цвета
   - Настройка длительности цикла (5-300 секунд, по умолчанию 60)
   - Выбор стиля движения (плавное/пошаговое)

3. ✅ **Системные настройки**
   - Автозапуск с Windows
   - Показ/скрытие иконки в системном трее
   - Настройки сохраняются между сессиями

4. ✅ **Три уровня отображения**
   - **Уровень 1 (Базовый):** Простой круг
   - **Уровень 2 (Продвинутый):** Только цифры счетчика
   - **Уровень 3 (Эксперт):** Символ режима + цифры + единица измерения

5. ✅ **Режимы мотивации (8 режимов)**
   - 💵 Деньги - $XXX
   - 👍 Популярность - 👍 XXX
   - ⬆️ Саморазвитие - Level XXX
   - 🚀 Успех - Очков успеха: XXX
   - ⏰ Здоровье - -XXX мин
   - 💪 Спорт - +XXX г
   - 🎨 Творчество - Мастерство: XXX
   - 📚 Обучение - Знаний: XXX

6. ✅ **Счетчики и статистика**
   - Счетчики обновляются каждую минуту
   - Статистика по всем режимам в окне настроек
   - Сброс всех счетчиков горячей клавишей (по умолчанию Ctrl+Shift+R)

7. ✅ **Горячие клавиши**
   - Настраиваемая горячая клавиша для сброса счетчиков

8. ✅ **GitHub публикация**
   - Проект опубликован на GitHub
   - Автоматическая сборка через GitHub Actions

9. ✅ **Портативный .exe файл**
   - Сборка portable версии приложения
   - Не требует установки

10. ✅ **Применение настроек в реальном времени**
    - Настройки применяются сразу при изменении
    - Не требуется кнопка "Применить"

## 🎯 Концепция

**Философия:** Memento mori - напоминание о времени через визуальный объект, видимый боковым зрением, не требующий концентрации внимания.

**Принципы:**
- Объект движется вверх за заданное время
- Виден боковым зрением (не отвлекает)
- Символизирует достижение целей
- Мотивирует использовать каждую минуту продуктивно

## 📝 Технические детали

### Технологии:
- Electron
- Node.js
- HTML/CSS/JavaScript

### Структура проекта:
- `main.js` - главный процесс Electron
- `index.html` - overlay окно с движущимся объектом
- `settings.html` - окно настроек
- `src/config/modes.js` - конфигурация режимов мотивации
- `src/utils/counters.js` - логика работы со счетчиками
- `src/store/settingsStore.js` - хранение настроек
