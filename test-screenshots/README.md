# Screenshot Tests

This directory contains screenshots generated by automated visual tests.

## Running Screenshot Test

```bash
npm run test:screenshot
```

The test will:
1. Launch Electron application
2. Open todo window
3. Load large demo data
4. Wait for rendering
5. Capture screenshot
6. Save to `test-screenshots/hierarchy-visualization.png`

## Viewing Screenshots

After running the test, check the screenshot file to verify the hierarchy visualization is correct.

The screenshot should show:
- Continuous vertical lines from parent tasks through all children
- Horizontal lines connecting vertical lines to child tasks
- Proper indentation for each hierarchy level
- No colored bars (old visualization removed)
