# It's time!

> *Не думай о секундах свысока*

**Новый подход к продуктивности.** Напоминание о том, что каждая минута имеет значение. Не учит тайм-менеджменту, а просто напоминает, что время идёт. Ещё можно декомпозировать дела на мелкие и стараться уложиться в цикл.

## 🌟 Философия

**It's time!** — это не просто виджет. Это постоянное напоминание о том, что время проходит. Каждая минута уникальна и неповторима. 

Поначалу это бесит. Красный круг, неумолимо ползущий вверх по краю экрана, показывает, как проходят ваши минуты. Но, как и в любой другой правде, человек проходит все стадии принятия и становится лучше.

Это вещь, которая не дает забыть о времени и заниматься фигнёй. Это постоянное напоминание о том, что время — это не деньги. Время — это всё, что у вас есть.

**Memento mori** — помни о смерти. Помни о времени. Помни о том, что каждая минута имеет значение.

## ✨ Особенности

- 🔴 **Яркий красный круг** — движется вдоль правого края экрана снизу вверх
- ⏱️ **Равномерное движение** — преодолевает высоту монитора за минуту (настраивается)
- 👻 **Полупрозрачный и не кликабельный** — не мешает работе, не перехватывает клики
- 🎨 **Полностью настраиваемый** — цвет, размер, скорость, режим движения
- 🎯 **Три уровня отображения** — базовый (круг), продвинутый (счетчик), эксперт (мотивация)
- 💪 **Режимы мотивации** — деньги, популярность, саморазвитие, успех, здоровье, спорт, творчество, обучение
- 📊 **Статистика** — отслеживание прогресса по каждому режиму
- 🔧 **Удобные настройки** — доступны через иконку в системном трее
- 💾 **Сохранение настроек** — все параметры запоминаются между запусками
- ⌨️ **Горячие клавиши** — сброс счетчиков одним нажатием

## 🚀 Установка

### Требования

- Windows 11 (или Windows 10)

### Быстрый старт

1. Скачайте последнюю версию `It's time!.exe` из [релизов](https://github.com/cynepnaxa2/its-time/releases)
2. Запустите файл — настройки откроются автоматически при первом запуске
3. Настройте параметры и начните работать!

### Для разработчиков

1. Клонируйте репозиторий:
```bash
git clone https://github.com/cynepnaxa2/its-time.git
cd its-time
```

2. Установите зависимости:
```bash
npm install
```

3. Запустите приложение:
```bash
npm start
```

### Сборка для распространения

Для создания исполняемого файла:
```bash
npm run build:portable
```

Или используйте скрипт:
```bash
# Windows
build.bat

# Linux/Mac
./build.sh
```

## ⚙️ Настройки

Откройте настройки через иконку в системном трее (правый клик → "Открыть настройки"):

### Уровни отображения

- **Базовый** — простой круг. Рекомендуется всем, кто начинает.
- **Продвинутый** — только счетчик. Может демотивировать.
- **Эксперт** — счетчик и мотивация зачем работаем.

### Режимы мотивации (только для уровня "Эксперт")

- 💵 **Деньги** — каждый цикл +$1
- 👍 **Популярность** — каждый цикл +1 лайк
- ⬆️ **Саморазвитие** — каждый цикл +1 XP, каждые 60 XP = +1 уровень
- 🚀 **Успех** — каждый цикл +1 клиент
- ⏰ **Здоровье** — каждый цикл 1 минута омоложения
- 💪 **Спорт** — каждый цикл + 1 грамм к силе
- 🎨 **Творчество** — каждый цикл +1 идея
- 📚 **Обучение** — каждый цикл +1 факт / аргумент

### Внешний вид

- **Диаметр объекта** — от 10 до 200 пикселей
- **Прозрачность** — от 0.1 до 1.0
- **Цвет** — любой цвет на выбор

### Анимация

- **Длительность цикла** — время, за которое объект проходит высоту экрана (по умолчанию 60 секунд)
- **Режим движения** — плавно или ступеньками

### Горячие клавиши

- **Сброс счетчиков** — настраиваемая комбинация клавиш (по умолчанию Ctrl+Shift+R)

## 🎯 Как это работает

**It's time!** создает прозрачное окно, которое всегда находится поверх всех окон. Объект (круг, счетчик или символ мотивации) движется снизу вверх, визуализируя течение времени. Окно полностью прозрачно и не перехватывает клики мыши, поэтому вы можете работать как обычно, но при этом постоянно видите напоминание о времени.

**По умолчанию:** круг диаметром 60 пикселей проходит высоту экрана за 60 секунд, затем цикл повторяется.

### Декомпозиция задач

Один из способов использования — декомпозировать дела на мелкие задачи и стараться уложиться в один цикл. Каждый цикл становится маленькой победой.

Напоминает о том, что время проходит. Напоминает о том, что каждая минута важна. Напоминает о том, что вы не можете остановить время, но можете использовать его осознанно.

**Поначалу это бесит.** Вы будете раздражаться на этот красный круг. Но со временем вы поймете: это не раздражение. Это осознание.
