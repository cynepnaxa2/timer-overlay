## 🌟 Философия

Поначалу это бесит. Красный круг, неумолимо ползущий вверх по краю экрана, показывает, как проходят ваши минуты. Но, как и в любой другой правде, человек проходит все стадии принятия и становится лучше.

**Memento mori** — помни о смерти. Помни о времени. Помни о том, что каждая минута уникальна и неповторима.

Это не просто виджет. Это вещь, которая не дает забыть о времени и заниматься фигнёй. Это постоянное напоминание о том, что время — это не деньги. Время — это всё, что у вас есть.

---

## ✨ Особенности

- 🔴 **Яркий красный круг** — движется вдоль правого края экрана снизу вверх
- ⏱️ **Равномерное движение** — преодолевает высоту монитора за минуту (настраивается)
- 👻 **Полупрозрачный и не кликабельный** — не мешает работе, не перехватывает клики
- 🎨 **Полностью настраиваемый** — цвет, размер, скорость, режим движения
- 🔧 **Удобные настройки** — доступны через иконку в системном трее
- 💾 **Сохранение настроек** — все параметры запоминаются между запусками

## 🚀 Установка

### Требования

- Windows 11 (или Windows 10)
- Node.js 16+ (для разработки)

### Быстрый старт

1. Клонируйте репозиторий:
```bash
git clone https://github.com/cynepnaxa2/timer-overlay.git
cd timer-overlay
```

2. Установите зависимости:
```bash
npm install
```

3. Запустите приложение:
```bash
npm start
```

### Сборка для распространения

Для создания исполняемого файла используйте [electron-builder](https://www.electron.build/) или [electron-forge](https://www.electronforge.io/).

---

## ⚙️ Настройки

Откройте настройки через иконку в системном трее (правый клик → "Открыть настройки"):

- **Диаметр круга** — от 10 до 100 пикселей
- **Прозрачность** — от 0.1 до 1.0
- **Время подъема** — от 5 до 300 секунд
- **Цвет круга** — любой цвет на выбор
- **Режим движения** — плавно или ступеньками (1/60 высоты в секунду)

---

## 🎯 Как это работает

Виджет создает прозрачное окно, которое всегда находится поверх всех окон. Красный круг движется снизу вверх, визуализируя течение времени. Окно полностью прозрачно и не перехватывает клики мыши, поэтому вы можете работать как обычно, но при этом постоянно видите напоминание о времени.

**По умолчанию:** круг диаметром 20 пикселей проходит высоту экрана за 60 секунд, затем цикл повторяется.
