# Инструкции по сборке .exe файла

## ✅ Проверка требований

### Все требования реализованы:

1. ✅ **Поля для ввода значений цифрами** - Реализовано в `settings.html`
   - Текстовые поля рядом с ползунками для всех параметров
   - Синхронизация между ползунком и текстовым полем

2. ✅ **Размер круга до 200 пикселей, по умолчанию 60** - Реализовано
   - Минимум: 10px
   - Максимум: 200px
   - По умолчанию: 60px

3. ✅ **Предпросмотр круга** - Реализовано
   - Секция "Предпросмотр" в настройках
   - Обновляется в реальном времени при изменении параметров

4. ✅ **Чекбокс "Запускать вместе с Windows"** - Реализовано
   - В секции "Система" сверху
   - Сохраняется и применяется автоматически

5. ✅ **Чекбокс "Показывать в трее"** - Реализовано
   - В секции "Система" после автозагрузки
   - Управляет видимостью иконки в системном трее

6. ✅ **Благозвучные названия настроек** - Реализовано
   - "Размер круга" вместо "Диаметр"
   - "Прозрачность" вместо "Opacity"
   - "Длительность цикла" вместо "Время подъема"
   - "Стиль движения" вместо "Режим движения"
   - Секции: "Система", "Предпросмотр", "Внешний вид", "Анимация"

7. ✅ **Окно настроек при первом запуске** - Реализовано
   - Автоматически открывается при первом запуске
   - Проверка через `isFirstRun()`

---

## 🛠️ Сборка приложения

```bash
# 1. Установить зависимости (если еще не установлены)
npm install

# 2. Собрать приложение
npm run build:portable
```

---

## 📦 Результат сборки

После сборки приложение будет находиться в папке `dist/win-unpacked/`:
- `Its-time.exe` - главный исполняемый файл
- Все необходимые библиотеки и ресурсы

**Для использования:**
1. Скопируйте всю папку `dist/win-unpacked/` куда нужно
2. Запустите `Its-time.exe` - не требует установки, работает из папки

---

## 🧪 Тестирование как пользователь

1. **Скопируйте** `its-time-portable.exe` из папки `dist/`
2. **Запустите** файл на чистой Windows (или любой другой системе)
3. **Проверьте:**
   - ✅ Окно настроек открывается автоматически при первом запуске
   - ✅ Все поля для ввода работают (ползунки + текстовые поля)
   - ✅ Превью круга обновляется при изменении параметров
   - ✅ Чекбоксы работают (автозагрузка, показ в трее)
   - ✅ Круг появляется на экране после применения настроек
   - ✅ Настройки сохраняются между запусками

---

## 📝 Примечания

- Portable версия не требует установки
- Все настройки сохраняются в `%APPDATA%/It's time!/settings.json`
- При первом запуске автоматически открывается окно настроек
- Иконка в трее появляется только если включен чекбокс "Показывать в трее"
