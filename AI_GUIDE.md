## Development principles
- **Базовые правила:** Соблюдай все общие user rules, они будут предоставлены средой разработки либо отдельным файлом..
- **Инкапсуляция:** При разработке, если появляется логически независимый функционал, который можно вынести в отдельный файл и переиспользовать, то нужно так и сделать.
- **Итеративность:** Всегда разбивать доработку на маленькие кусочки и после каждого кусочка:
  - Прогонять тесты (`npm test`)
  - Проверять консоль браузера/приложения на отсутствие ошибок
  - Убеждаться, что функционал работает корректно
  - Только после этого переходить к следующему кусочку
- **Чистка кода:** После получения одобрения о том, что функционал работает, нужно просмотреть весь код на предмет оптимизации и уменьшения размера кодовой базы:
  - Найти неиспользуемые файлы и удалить их
  - Найти дублирование кода и вынести в переиспользуемые функции
  - Оптимизировать импорты и зависимости
  - Упростить сложные функции
  - Удалить неиспользуемый код

## 📁 Подробное описание файлов

### Главный процесс (Main process)
- `main.js`: Точка входа Electron. Создает окна (overlay, settings, todo), управляет треем, IPC-обработчиками, таймерами, глобальными хоткеями и автозагрузкой.

### Компонент Overlay (Индикатор)
- `index.html`: Рендерер оверлея. Анимирует индикатор вверх через CSS; реагирует на IPC (`counter-updated`, `mode-updated`, `level-updated`, `restart-cycle`).
- `preload/overlayPreload.js`: Экспонирует безопасное API (`overlayApi`) для оверлея.

### Компонент Settings (Настройки)
- `settings.html`: UI настроек. Живое обновление через IPC: размер, прозрачность, цвет, длительность цикла, автозапуск, режимы и статистика.
- `preload/settingsPreload.js`: Экспонирует безопасное API (`settingsApi`) для настроек.

### Компонент Todo (Задачи)
- `todo.html`: UI списка задач. Полноэкранное окно с иерархией. Подключает модули через `<script src="...">`.
- `preload/todoPreload.js`: Экспонирует безопасное API (`todoApi`) для рендерера задач.
- `src/todo/state.js`: Управление состоянием (focusedElement, activeTaskId, currentTodos, draggingTaskId, todoHotkeys).
- `src/todo/hierarchy.js`: Логика уровней вложенности, видимости задач и поиска потомков.
- `src/todo/hierarchyLines.js`: Отрисовка SVG-линий иерархии (дерево задач).
- `src/todo/dragDrop.js`: Логика перетаскивания задач.
- `src/todo/hotkeys.js`: Обработка клавиатурных команд (Insert, F5, Delete).
- `src/todo/renderer.js`: Ядро отрисовки (renderTask, renderTasks), управление экшенами и фокусом.

### Хранилище (Store)
- `src/store/settingsStore.js`: Персистентность настроек в JSON.
- `src/store/todoStore.js`: Персистентность задач. CRUD операции, сортировка, загрузка из файла и создание демо-задач.

### Утилиты и Конфиг
- `src/utils/style.js`: Сборка CSS-переменных для оверлея из настроек.
- `src/utils/counters.js`: Логика форматирования и обновления счетчиков.
- `src/utils/positioning.js`: Расчетbounds окон (например, привязка к правому краю).
- `src/utils/richEditor.js`: Утилиты для `contenteditable` (авто-размер, очистка вставки, сохранение с дебаунсом).
- `src/utils/trayIcon.js`: Генерация иконки для системного трея.
- `src/config/modes.js`: Конфигурация режимов мотивации (формулы, символы).

## ⚙️ Важные поведения
- **Прозрачность:** Оверлей полностью игнорирует события мыши (`pointer-events: none`).
- **Таймер:** Цикл анимации синхронизирован с `durationSeconds`. Хоткей сброса (`Ctrl+Shift+R`) перезапускает анимацию с начала.
- **Авто-сохранение:** В Todo-листе любые изменения текста сохраняются автоматически при вводе с задержкой (debounce).
- **Тесты:** Проект использует Jest. Unit-тесты лежат в `tests/unit/`, интеграционные — в `tests/integration/`.
